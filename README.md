# The Heart's Electrical System — website

Udkast til bandets website. Dansk som standard, engelsk kan vælges i menuen.

**Se sitet:** https://jacobsalmon.github.io/theheartselectricalsystem/

## Sådan slår du siden til

1. Læg indholdet af denne mappe i repoets rod på branch `main`.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `/ (root)` → Save.
3. Linket ovenfor virker efter et par minutter.

## Sådan giver du feedback

Åbn linket, og skriv din feedback som et **issue** (fanen Issues → New issue).
Skriv gerne hvilken side og hvilket afsnit det handler om, fx "Kontakt — fotogitteret".

## Om filerne

- `index.html` — hele sitet i én fil (React via CDN, alle styles indlejret)
- `assets/` — fotos, logo, albumcover og fire videoer

Syv sider: Forside, Om, Musik, Video, EPK, Presse, Kontakt.
